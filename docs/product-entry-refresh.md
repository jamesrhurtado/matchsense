# MatchSense product entry refresh

25 October 2026. Local product and presentation improvements.

The entry now leads with an interactive, explicitly prepared Pressure Swing
example instead of runtime configuration. Its 30 m progression and 2.0 → 0.4
nearby-opponent means come from the synthetic flagship documented in
`pressure-flagship.md`. The pitch is labeled as an illustrative diagram, not
exact observed coordinates. This example creates no session, calls no model and
claims no producer approval.

Visitors can change the example language and detail, inspect the measurement
windows and coverage, or listen using the browser's optional speech feature.
Producer and fan links have distinct destinations. The producer setup sits below
the example; experience, execution and recording selection are in Demo options.
Template execution is the explicit entry default. Selecting unavailable AI shows
a direct action to return to template preview, rather than silently falling back.
Producer authorization remains required for session creation.

The console has a shorter header, compact simulation status, publication guidance
in a disclosure, a shorter scrollable queue, and concise review instructions.
Non-highlight source context is labeled as context and limits rather than
presented as a claim of match significance. Invalid session links lead to a
recovery page with a return action; stale match controls are not shown there.

Verification uses an isolated template backend with match coverage enabled and
a copied standalone frontend on port 3180. Tests cover service-independent
example interaction, bilingual facts, AI unavailability, explicit template
selection, invalid-session recovery, opt-in speech cancellation, producer entry,
selection stability and the full flagship approval/viewer/Spanish/focus/recap
flow. Desktop and 390 px screenshots are generated during the browser checks.
Production compilation and TypeScript checks pass. No live model call, cloud
release, or validation with disabled fans is claimed by this UI refresh.
