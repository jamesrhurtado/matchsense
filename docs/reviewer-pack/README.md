# Reviewer handout pack

Version R1, 22 October 2026. Editable Word manuals and matching Markdown sources for the first formative WHY/NOW review round. No completed research is represented.

## Which file to give each person

- Football coach, analyst, scout or journalist: `01-football-reviewer.docx`.
- Sports producer, editor or content creator: `02-producer-reviewer.docx`.
- Casual or regular viewer: `03-viewer-reviewer.docx`.
- Bilingual football reviewer: `04-spanish-reviewer.docx`, written in Spanish.
- James or another session facilitator only: `00-facilitator-guide.docx`.

Send only the participant's assigned manual. The facilitator guide contains expected behavior and study controls; do not distribute it as participant preparation. Do not include the demo pitch, architecture reports or private agent mappings.

Each participant manual contains three pages: role and preparation, task instructions, and a reusable answer sheet. Duplicate the final page for each assigned output or task, or use separately labeled digital copies. The facilitator guide has five pages, including permission fields, preparation, blind comparison procedure, answer-key guidance, observation form and issue template.

Before sessions, the facilitator must provide the date/time/timezone, private return method, assigned application link and outputs, and independently checked evidence keys. There is no public access token in these documents. Blank logistical fields are intentional; no participants or schedule have been invented.

Start with one pilot, then freeze the instrument/build for the next round. Use independent sessions and separate producer replay state. Reviewers can answer verbally with a facilitator transcribing. Store completed forms and recordings outside Git; this folder is for blank materials only.

The preserved agent discovery packets use prompt v4.0; the current app uses v4.1. See the facilitator guide before comparing them. Do not describe anonymous content review and app usability as the same experiment.

Source references: `docs/next-iteration/reviewer-guide-v4.md`, `docs/user-study.md`, `docs/demo-script-v4.md`, `docs/next-iteration/quality-v4-handoff.md`, `simulator/context_replays.py`, and the local discovery rating instrument. This pack expands the existing protocol into participant-ready materials.
