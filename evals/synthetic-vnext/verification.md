## Failures found during development

The first focused run had five failures: four tests incorrectly demanded lateral
movement from a keeper supporting centrally, and one injected acquisition defect
was intercepted by the existing semantic feed guard before the intended new check.
Tests now allow appropriate central positioning and isolate the acquisition check.
No original expectation or movement bound was loosened.

Close-contact diagnostics exposed a long teammate convergence in one new support
lane; its newly authored, unpublished path was corrected. A later review unified
support/keeper targets with the actual episode ball rather than an approximate
separate corridor. Only new candidate exports were regenerated; the original 385
files and reference expectations remained unchanged. Final hashes are in the
provenance manifest.

Initial new browser assertions could accept a loading placeholder. They were
strengthened to require actual clock and exact approved bilingual text. Screenshots
were retaken and visually inspected. `browser-final.txt` is a clean full 16-case
run after the source and assertion fixes; earlier runs are retained separately.
