## The story to tell

**“A pass is a number. WHY/NOW gives it context, shows the supporting evidence, and lets a producer decide what reaches the audience.”**

Lead with the working product. The strongest sequence is: a meaningful comparison → inspectable evidence → accountable agent workflow → exact producer approval → personalized viewing → catch-up and editorial control. Keep infrastructure to one short explanation near the end.

## Four-minute main script

Timing is a rehearsal guide, not a required recording limit. Spoken passages are separated from operator actions.

### 0:00–0:25 — Start with the problem and the product

**Screen:** Producer studio, Moment 4 selected, pitch and candidate visible. Keep the synthetic-data designation visible. Avoid opening with a slide deck.

**Say:**

> “Watching a match, we can see a pass. The harder question is: what changed, and why should we pay attention now?
>
> This is WHY/NOW. It turns match observations into evidence-backed explanations that a producer can review and viewers can explore. Today, I’m using a synthetic football replay, paused so we can inspect one moment.”

### 0:25–1:00 — The strongest reveal: context you can inspect

**Screen:** Open **Show why** and use the evidence stages. Show the previous-pass comparison wherever available in the producer evidence view. If its full bars are only available in the companion, show the producer's supported comparison now and reserve the bars for after approval.

**Say:**

> “This pass moved the ball 30 metres forward. The previous three completed passes moved it 8, 12, and 16 metres forward.
>
> WHY/NOW makes that comparison explicit and lets us inspect the sequence behind it. The statement is deliberately precise: farther forward than those three passes. We’re not calling it the best pass of the match or claiming we know the player’s intent.”

**Operator note:** Point to the actual source evidence. Do not say the metric is total pass length; it is forward displacement. Close the evidence panel before the next step.

### 1:00–1:35 — Show the decision process

**Screen:** Open **Processing & review trace**. Use one of the following passages, according to the actual mode.

**If this session ran the Foundry workflow, say:**

> “Here is the actual review trace. The Story Director selects supported facts and an angle. Code renders the measurements and wording, and the Claim Reviewer checks the proposal against the evidence. Both roles use the same bounded observation window.
>
> A failed or invalid proposal can receive a limited repair or a labeled factual fallback. The agents cannot publish.”

**If this session uses local templates, say:**

> “This session is running in local template mode, so these explanations use deterministic facts and wording without model calls.
>
> The implemented AI path adds a Story Director and Claim Reviewer around the same evidence and rendering checks. We’ve exercised that path separately with real model calls. In either mode, publication belongs to the producer.”

**Operator note:** Do not imply a repair happened unless the displayed trace records one. If you explicitly selected the emphasis during setup, mention: “I selected this comparison as the editorial emphasis.”

### 1:35–1:55 — Make human control visible

**Screen:** Close diagnostics. Click **Approve** for Moment 4. Switch to the viewer companion for the same session. Show the newly approved explanation and overlay state.

**Say:**

> “I’m approving this exact revision. Now it becomes available to the audience. If I edit the story or its supporting evidence changes, that approval does not carry over to a replacement. The new version needs review.”

### 1:55–2:40 — One approved story, different ways to understand it

**Screen:** In the companion, open **Inspect the facts**, select the comparison clause, show the signed bars, and briefly expand **Original values and sources**. Then change language to Spanish, choose detailed explanation, and focus on the actual receiver. Open **Ver evidencia** if time allows; close it afterward.

**Say:**

> “The viewer can check the comparison visually and open the original values and sources.
>
> Now I’ll switch to Spanish, add detail, and focus on the receiving player. The explanation changes its language and perspective while staying tied to the same approved facts.
>
> These choices select variants prepared before approval. They don’t trigger a new model call for every viewer, and they don’t change what the producer authorized.”

**Operator note:** Let the Spanish text remain visible for several seconds. Return to English and general focus before the history segment so the next control labels match this script.

### 2:40–3:20 — Keep the match understandable as it moves on

**Screen:** Return to studio. Disclose the jump, advance to **120**, wait for Moment 5, select it, and approve it. Switch to the companion. Open **Approved history**, select Moment 4, show the earlier-moment banner, then click **Return to live**. Open **Catch me up**.

**Say:**

> “I’m jumping forward in the replay to the next reviewed moment. Each pass has its own story and approval; a new one does not overwrite the earlier ones.
>
> As a viewer, I can revisit an earlier explanation and return to the current moment without changing anyone else’s view. If I missed part of the action, ‘Catch me up’ builds a recap from the stories the producer has approved.”

**Operator note:** If generation needs more time, allow it or label the recording cut “After review completes.” Do not present an edited wait as real measured latency. Recaps may group similar moments; expand a group when useful instead of promising five separate cards.

### 3:20–3:45 — Show the trust boundary working

**Screen:** Close recap. In the studio select an **earlier** approved story, such as Moment 1, and click **Retract**. Return to the viewer; show its history count update and reopen **Catch me up**. Moment 5 remains approved.

**Say:**

> “Editorial control continues after publication. I can retract an earlier story. It leaves the viewer’s approved history and recap, while the other approved moments remain available. Approval, expiry, and retraction are separate states.”

**Operator note:** This is an intentional producer retraction, not an automatically detected source correction. Rehearse it on the disposable demo session.

### 3:45–4:10 — Engineering and close

**Screen:** Return to the clean viewer view. Optionally show a verified static architecture diagram for five seconds. The architecture website is currently a handoff brief; do not promise to open a finished site unless it has actually been built.

**Say:**

> “The Azure engineering setup uses Container Apps, Event Hubs, Cosmos DB, and Foundry model access. Our current candidate has passed 325 backend tests, 17 local browser tests, and a 168-case synthetic regression suite.
>
> WHY/NOW brings together context, inspectable evidence, producer control, and accessible explanations—so viewers can understand what changed and why it deserves attention.”

**Operator note:** These counts are the recorded 22 October verification snapshot; refresh them if the build changes. If showing the local candidate, leave “Local v0.5 candidate” visible and do not say these latest changes are already deployed to Azure.

## If a rehearsal step fails

- **No comparison appears:** verify history A, Moment 4, 95 s, current v0.5 build, completed review, and supported emphasis. Do not substitute invented numbers.
- **No current overlay appears:** check the replay clock, selected story, approval, and expiry. Create a fresh session if necessary. Earlier approved history can remain after an overlay expires.
- **AI fallback appears:** state that the visible output uses factual fallback. Keep demonstrating evidence and approval; do not call it successful agent collaboration.
- **Only an older hosted build is available:** use the original multi-moment scenario in `docs/demo.md`, and omit features missing from that build.
- **A model request is slow:** keep the replay paused. Explain the real wait or disclose a cut. Avoid any numerical speed claim without an actual measurement.
